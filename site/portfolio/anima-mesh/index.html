ad hoc no spec preceded the code. The structure came from releases: 38 tags through v0.16.2, a changelog per minor line, and platform failures written down as learnings.

AnimaMesh runs recurring back-office work from a private repo: compliance checks, bookkeeping prep, document memory, governance, research, and inbound triage. A human remains the approval gate for money, filings, publishing, credentials, and access.

Cloud execution is primary. A Worker reads the brain as one tarball, runs the agents that are due, verifies their artifacts, and lands one commit before a brief or reply is sent. The CLI uses the same engine for setup, recovery, and subprocess-only harnesses.

From the docs: "the initiative inverts: you stop driving the operations and start reviewing them."

Nine agent concepts run on daily, weekly, monthly, and quarterly rhythms. Due spokes run sequentially; the hub runs last and reads their fresh reports. Discord and Gmail feed direction runs. A separately credentialed dashboard shows the evidence and can trigger a beat. Role-declared reads: paths are inlined into every prompt, with missing context named instead of silently dropped.

Safety lives in code, never in prompts

Everything between wake-up and gate is model judgment. Gates, ladder, ledger, and verifiers are deterministic code.

Five constitutionally gated action classes cover money movement, government filings, publishing, credentials, and access expansion. Three reversible write paths ship today: schedule updates, draft writes, and defect reports. Each request is parsed, checked against the same ladder and whitelist gate, and ledgered whether applied or denied.

What this project collects

Four coordination approaches

Three coordinator systems came before it, each with a different coupling: the continuous agent below, a tightly coupled monolith; the conversion factory's hub and four spokes; and the content factory's loosely coupled A2A mesh. Anima Mesh is the extracted lesson: keep coordination in shared state and model judgment, while deterministic code owns gates, ledgers, verification, and scheduling.

Operational evidence

The private brain records 38 commits authored by the mesh, 330 append-only ledger entries, and 81 reports since July 6. The cloud schedule and the repo history are the evidence surfaces; the portfolio only summarizes them.
