| # AEM Rockstar 2024<br>*The prologue*                                                                                   |
|                                                                                                                         |
| Aug 2023 - Mar 2024 · won at Adobe Summit · repo public Nov 2024                                                        |
|                                                                                                                         |
| **ad hoc** hand-written Java and jQuery, versioned 1.0 → 1.2 through fall 2023. The AI was the feature, not the author. |
|                                                                                                                         |
| The pitch that won AEM Rockstar at Adobe Summit 2024: personalization at scale, inside AEM's own authoring UI. An       |
| author opens an experience fragment, types "rewrite this for ages 13 to 17," reviews a side-by-side table of every      |
| proposed change, and one click later has a new fragment variation open in the editor.                                   |
|                                                                                                                         |
| The design constraint that shaped it: add capability without adding surface. Generation is a Sling selector on the      |
| stock experience-fragment page type, the UI is one clientlib injected into the stock properties editor, and writes go   |
| through AEM's own copy and POST machinery. No new endpoints, no new editor, no writes without review.                   |

| good at analyzing content, transforming content and       |                   |

| Showcase (story, wide)                                                                          |
+------------------------------------------------------------------------------------+------------+
| The frontend is where most of the craft went. A \~270-line                         |            |
| Granite/jQuery clientlib hooks `foundation-contentloaded`, derives                 |            |
| the fragment path from the properties-editor URL, and builds the                   |            |
| review table in the DOM: path, original value, generated value, one                |            |
| row per property the QueryBuilder walk found. A continue-chat toggle               |            |
| threads the chat id back, so the model refines its last answer                     |            |
| instead of starting over. Approval clones the variation through `/bin/wcmcommand`, |            |
| writes the accepted values with a Sling POST, and links straight into              |            |
| the new fragment's editor. A second clientlib does the same for whole              |            |
| pages.                                                                             |            |
|                                                                                    |            |
| None of this code was AI-written; in August 2023 the AI was the                    |            |
| product, GPT-4 by default with the model behind a config. The shape                |            |
| it demoed is the one everything above formalizes later as propose and              |            |
| dispose: the model proposes values, a human reviews every row, and                 |            |
| deterministic machinery does the writing. In 2023 that pattern was a               |            |
| jQuery table.                                                                      |            |

| **Ask**                            | The console sends the prompt, plus the last chat id when Continue Chat is ticked, as a GET                                      | properties.js                      |
|                                    | to the variation's `jcr:content.aipreview.json`.                                                                                |                                    |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| **Route**                          | Sling picks the servlet by the stock experience fragment page type, the `aipreview` selector and the `json` extension.          | ExfragGptServlet                   |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| **Find the content**               | QueryBuilder walks the variation for nodes with a `text` or `jcr:description` property, skipping any path with `actions` in it. | searchProperties                   |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| **Rewrite**                        | One Chat Completions call per property: a system message, then the prompt template wrapped around that property's value.        | useGptConvertStrings               |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| **Review**                         | The servlet returns a path, an original value and a generated value per row, and the console draws the table.                   | displayTableData                   |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| **Copy**                           | Create Variation posts `cmd=copyPage` with the new name, so the copy lands next to the original.                                | /bin/wcmcommand                    |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| **Save**                           | One Sling POST to the copy writes every generated value, plus a `jcr:title` made from the variation name.                       | Sling POST servlet                 |
+------------------------------------+---------------------------------------------------------------------------------------------------------------------------------+------------------------------------+
| Two clicks, at `01d6c49`, the last commit before the talk. Steps 1 to 5 are one GET request and its response.                                                                                             |
